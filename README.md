# Ruin Scholar — Gamified Study Companion

An infinite 2D pixel adventure through ruined wilderness. Explore villages and dungeons, complete study quests, and defeat dungeon guardians by answering subject questions.

## Play

Open `index.html` in a modern browser (or serve the folder locally).

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Features

- Infinite procedural world (chunk-based, Minecraft-style)
- Villages with quest NPCs and dungeons with bosses
- Subjects: Math, Science, History, English, Geography
- Difficulty: Easy · Medium · Hard · Raid
- Quests: one question — correct grants loot; wrong respawns at the gate
- Bosses: three escalating questions — fail loses items and drops a level
- Settings: field of view, render distance, move speed, minimap, particles

## Controls

| Action | Keys |
|--------|------|
| Move | WASD / Arrow keys |
| Interact | E / Tap |
| Inventory | I |
| Settings | Esc |

Touch controls appear on mobile.
